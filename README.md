# Beam Designer

Beam Designer is a Python desktop app for preliminary steel beam analysis. It displays shear, moment, and deflection diagrams, performs bending and deflection checks, and can save designs and export results as CSV or PDF. It is an educational tool, not a substitute for a qualified engineer or code-compliant design.

## Requirements

Install Python 3.10 or newer with Tkinter. The app uses only Python's standard library, so no additional pip packages are required. If Tkinter is missing, install it using your operating system's Python or Tkinter package.

## Run

From the project folder, run:

```sh
python beam_designer.py
```
